# Rubric: is this a good first issue?

## Checks

| Check | Evidence | Pass condition | Weight |
|---|---|---|---|
| maintainer-alive| the last 5 default-branch commit dates | at least 2 commits in last 90 days | required |
| responds-to-issues | maintainer reply times in last 5 issues | a reply within 30 days | preferred |
| shiped-recently | latest release is recent | a release in the last 90 days | preferred |
| unclaimed |  linked PRs | is none or empty and state is 'open' | required |
| good-to-start | labels | contains 'good first issue' | required |

## Verdict rule

Accept if every required check passes; preferred checks never change the verdict, they rank accepted issues; unclear counts as fail.
